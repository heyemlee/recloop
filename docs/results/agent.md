# Shopping assistant: offline evaluation

Generated by `make agent-eval` (`agent/eval/run.py`, then `agent/eval/report.py`); do not
edit by hand. Design: `docs/design.md` §10. Cases: `agent/eval/cases.jsonl`, generated by
`make agent-cases` from templates and catalog attributes.

## Setup

- 150 cases in 12 templates (below); each has gold constraints, and the ones that refer to an earlier purchase carry their own purchase history.
- Items table at run time: 3,459 items, 3,347 in stock, 2,967 with a known price (fingerprint `697c6108ea5a`). No orders had been placed, so stock is as `make ingest` sets it (simulated, fixed seed): a fresh database, as after `make setup`.
- Every agent shares the pipeline: tools (`search_items`: BM25 + pgvector, RRF k=60, price / stock / category filters in SQL; `get_item_details`; `get_purchase_history`), code checks of every constraint on the item rows, device matching in code, replies rendered from the rows. At most 3 items per reply.
- Agents: **baseline** parses with rules (budget regex, category aliases, a brand dictionary, 'genuine / original / OEM', 'for / with <model>'), no language model. **oracle** is handed the gold constraints: the ceiling of the pipeline when the request is understood perfectly. The oracle variants change only the search.

## Where the baseline fails

- 53 of 150 baseline replies show at least one item that breaks a gold constraint; the oracle's: 0. The checks run on what the parser understood, so a misread request passes its own checks and fails the gold ones.
- Requests the catalog can satisfy (142): baseline shows a satisfying item in 72.5%, the oracle in 100.0%. Requests it cannot (8): nothing violating shown in 100.0% (oracle 100.0%).
- Device requests: 85.3% of the baseline's shown items there are code-confirmed compatible (oracle 93.0%); the rest are labelled 'not confirmed' in the reply.

## Search ablation (gold constraints)

With the gold constraints every item that passes the SQL filters meets the hard constraints, so success above cannot separate search variants. | oracle-vector | gold constraints, pgvector only | 91.5% | 1 |
